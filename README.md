# Rahel Hirzel – Website-Entwurf

Statische Website ohne Buildprozess. `index.html` im Browser öffnen oder die drei HTML-Dateien auf einen Webserver laden.

## Vor Veröffentlichung

1. Rahel bestätigt Angebot, Ablauf, FAQ und ihren persönlichen Text.
2. Beispielbilder durch freigegebene eigene Bilder ersetzen und Alternativtexte aktualisieren.
3. Betreuungsgebiet, Qualifikationen, Adresse und Kontaktangaben ergänzen.
4. In `index.html` `EMAIL_EINTRAGEN` an beiden Stellen durch die echte Adresse ersetzen.
5. Impressum und Datenschutz anhand des gewählten Hostings und der tatsächlichen Verarbeitung fertigstellen.
6. Externe Google Fonts lokal hosten oder durch Systemschriften ersetzen; Bilder ebenfalls lokal ablegen.
7. Domain und HTTPS im Hosting einrichten; mobile Ansicht und E-Mail-Link testen.

Das Kontaktformular öffnet einen Mailentwurf; es gibt keinen Server und keine automatische Übermittlung. Medizinische Daten sollten nicht über ein gewöhnliches Kontaktformular angefragt werden.
